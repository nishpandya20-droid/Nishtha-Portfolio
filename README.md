# Nishtha Pandya — Brand & Visual Communication Designer Portfolio

A responsive, animated portfolio website crafted for **Nishtha Pandya** (Brand & Visual Communication Designer with Computer Science roots).

Transformed from a 44-slide Canva presentation into a modern, fluid web experience with micro-animations, filterable project galleries, interactive case study breakdowns, dark/light themes, and an embedded 44-slide Canva deck presentation player.

## 🚀 How to Run Locally

### Option 1: Double Click
Simply double-click `index.html` in your file explorer to open it in any modern browser!

### Option 2: Local HTTP Server (Recommended)
Open a terminal in this folder and run:
```bash
# Python 3
python -m http.server 8080
```
Then visit `http://localhost:8080/` in your browser.

## 🌐 Free 1-Click Deployment

### GitHub Pages:
1. Push this folder to a GitHub repository (e.g. `username/portfolio`).
2. Go to **Settings > Pages**.
3. Under **Branch**, select `main` / `root` and click **Save**.
4. Your website is live in seconds at `https://<username>.github.io/<repo>`!

### Netlify / Vercel:
Drag and drop this entire folder into [Netlify Drop](https://app.netlify.com/drop) or deploy via Vercel with zero configuration required.
